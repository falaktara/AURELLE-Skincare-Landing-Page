# AURELLE — Luxury Skincare Landing Page

## About the Project

AURELLE is a fictional luxury skincare brand created as part of my Frontend Web Developer Internship at Barakah TechLabs.

The website features an elegant and modern design with a warm, neutral colour palette.

## Technologies Used

* HTML5
* CSS3
* Bootstrap 5

## Features

* Responsive navigation bar
* Hero section
* Skincare product collection
* Six product cards
* Brand story section
* Customer testimonials
* Newsletter subscription demo
* Contact section
* Footer with copyright information
* Responsive layout

## Project Structure

```text
AURELLE-Skincare-Landing-Page/
├── index.html
├── style.css
└── README.md
```

## Purpose

The purpose of this project is to practice Bootstrap, responsive web design, HTML structure, and CSS styling.
